# 📖 Quran Mazid - Modern Quran Web Application

[![Next.js](https://img.shields.io/badge/Next.js-15.0-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.0-blue?style=for-the-badge&logo=tailwind-css)](https://tailwindcss.com/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue?style=for-the-badge&logo=typescript)](https://www.typescriptlang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

**Quran Mazid** is a production-ready, highly responsive, and feature-rich Quran application designed with a focus on modern aesthetics (Glassmorphism) and seamless user experience. Built with the latest Next.js 15, it provides a fast and spiritual environment for reading and studying the Holy Quran.

---

## ✨ Key Features

### 🕌 Core Reading Experience
- **Multiple Arabic Fonts:** Choose between classic Indo-Pak (Amiri) and elegant slim styles (Lateef).
- **Customizable Typography:** Adjust Arabic and Translation font sizes for comfortable reading.
- **Surah Index:** A beautiful grid-based index of all 114 Surahs with detailed metadata.

### 🔍 Advanced Navigation & Search
- **Jump to Ayah:** Directly navigate to any specific Ayah within a Surah instantly.
- **Global Search:** Powerful search engine to find Ayahs using English words or Arabic text.
- **Sticky Navbar:** Access navigation and settings from anywhere on the page.

### ❤️ Personalization & Audio
- **Favorites System:** Save your favorite verses locally for quick access even offline.
- **Audio Playback:** High-quality audio recitations for every Ayah by renowned Qaris.
- **Real-time Countdown:** Live countdown for major Islamic events like Eid-ul-Adha.

---

## 🚀 Tech Stack

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Dark Mode First)
- **Icons:** [Lucide React](https://lucide.dev/)
- **State Management:** React Context API (Settings, Favorites, Search)
- **API:** [Al-Quran Cloud API](https://alquran.cloud/api)
- **Deployment:** [Vercel](https://vercel.com/)

## 🛠️ Installation & Setup

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/imranhossain2024/quran-web-app.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd quran-web-app
   ```

3. **Install dependencies:**
   ```bash
   npm install
   # or
   pnpm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   # or
   pnpm dev
   ```

5. **Open your browser:**
   Navigate to `http://localhost:3000` to see the application in action.
